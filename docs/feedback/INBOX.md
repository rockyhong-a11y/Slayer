## 작성법 (사용자용)

아래 "대기 중"에 한 줄씩 적으면 된다. 형식은 자유. 예:

```
- [ ] 전투가 너무 빨리 끝난다. 교환 횟수를 늘려라.
- [ ] 보상 화면 글씨가 작다.
- [ ] B1 승률 밴드를 30~50%가 아니라 20~35%로 바꿔라.
- [ ] 캡처가 전부 검은 화면이다. 먼저 고쳐라.
```

  요구한다. 완료 기준을 루프가 임의로 손대지 않기 위해 **고치지 않고 질문만 남긴다.**

  (지금도 `victory` 캡처는 찍어서 육안 확인하고 있다. 기준에 안 들어가 있을 뿐이다.)
  > **다음 이터레이션에게:** 이건 작업이 아니라 **사용자 답을 기다리는 질문**이다.
  > 답이 안 달려 있으면 이 항목은 건너뛰고 바로 STATUS의 "다음 할 일 큐"로 가라.
