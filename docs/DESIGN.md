# DESIGN — 무엇을 만드는가

## 한 줄 정의

**Slayer** — 게임 장르의 HUD(정보창)를 바닥에 눕혀 스테이지로 쓰는 탑뷰 캐주얼 액션 웹앱.
체력바 뒤에 숨고, 타이머로 적을 터뜨리고, 필살기 게이지로 쓸어버린다.
같은 전장을 **2D(브롤스타즈식 탑뷰)** 와 **3D(둠식 1인칭)** 로 언제든 바꿔 가며 싸운다.

## 핵심 규칙

1. **HUD가 곧 지형이다.** 화면에 붙어 있어야 할 UI 요소가 전장에 서 있는 구조물이다.
2. **구조물은 엄폐물이자 무기다.** 각 요소는 원래 HUD에서 하던 일을 그대로 전장에서 한다.
3. **2D와 3D는 같은 세계다.** 카메라만 바뀐다. 전환은 컷이 아니라 위에서 눈높이로 내려가는 다이브라서 방향 감각이 끊기지 않는다.

## 2D ↔ 3D — 왜 전환하는가

| | 2D (탑뷰) | 3D (1인칭) |
|---|---|---|
| 시야 | 전장을 넓게 본다 | 정면만 본다 |
| 피해 | 10 | **20** |
| 사거리 | 9 | 사실상 무제한 |
| 조작 | 오른쪽 스틱 방향으로 즉시 조준 | 오른쪽 스틱 좌우로 몸을 돌린다 |

무리가 붙으면 2D로 빠져나오고, 표적이 정해지면 3D로 녹인다.
전환에는 쿨다운이 없다. 방향(조준)은 전환해도 유지된다.

## 스테이지 1 — 대전 격투 HUD

x는 왼쪽→오른쪽, z는 위→아래. HUD가 화면에 보이는 배치 그대로다 (32 × 20).

| HUD 요소 | 전장에서의 모습 | 엄폐 | 무기로서의 쓰임 |
|---|---|---|---|
| **체력바** (P1·P2) | 위쪽의 긴 벽 2개 | 탄환을 막는다 | 벽의 **길이가 곧 체력**. 적 탄환에 맞으면 가운데 쪽 끝부터 줄어든다. 라운드마다 다시 찬다 |
| **라운드 타이머** | 위쪽 가운데 블록, 숫자가 실제로 줄어든다 | 탄환을 막는다 | 20초마다 **TIME UP** — 반경 5 안의 적을 전부 처치. 플레이어도 40 피해 |
| **필살기 게이지** | 아래쪽 낮은 바 2개 | 이동만 막는다 (넘겨 쏠 수 있다) | 처치 1회당 20% 충전. 가득 차면 양 끝 **패드**를 밟아 슈퍼 레인 전체에 빔 |
| **초상화** (P1·P2) | 위쪽 양 모서리 상자 | 탄환을 막는다 | P2 쪽에서 적이 입장한다 |
| **FIGHT 글자** | 가운데 블록 5개 | 탄환을 막는다 | — |
| **라운드 램프** | 체력바 아래 바닥 등 3개 | — | 이긴 라운드만큼 켜진다 |

체력바가 초상화 쪽에 고정되고 가운데부터 닳는 이유: 엄폐를 잃을수록 전장 한가운데, 타이머 바로 옆이 먼저 열린다.

### 흐름

`ROUND 1 → FIGHT! → 적 전멸 → ROUND 2 → … → 3라운드 승리 = YOU WIN`, 체력 0 = `K.O.`
라운드를 이기면 체력 30 회복. 적은 두 종류다.

- **그런트** — 걸어와서 때린다. 엄폐물을 돌아서 온다(길찾기).
- **슈터** — 거리를 두고 쏜다. 체력바를 닳게 하는 건 이쪽 탄환이다.

## 수치

전부 `src/game/config.js` 한 파일에 있다. 다른 곳에 숫자를 흩뿌리지 않는다.

난이도는 `npm run balance`로 맞췄다. 도망치며 쏘기만 하는 사람 흉내 봇 60판 기준:

| 플레이 방식 | 승률 |
|---|---|
| 2D만 | 43% (26/60) |
| 3D만 | 75% (45/60) |
| 상황 따라 전환 | **90%** (54/60) |

봐야 할 것은 절대값이 아니라 **순서**다 — 전환하는 쪽이 한 시점만 쓰는 쪽보다 높아야 전환할 이유가 있다.

> ⚠️ 이 수치는 **봇 기준**이다. 봇은 엄폐·타이머·슈퍼를 쓰지 않고, 터치 조작의 어려움도 모른다.
> 사람이 실제 폰으로 해본 결과가 아니다. 첫 플레이 후 `config.js`를 다시 만져야 할 가능성이 높다.

## 아트

- **3D 모델**은 Blender(`tools/blender/build_models.py`)로 생성한다. 캐릭터 3종, 초상화 틀, 타이머 몸체, 패드.
- **2D 아트**는 슬롯 방식이다. `public/art/manifest.json`에 파일을 지정하면 그 그림을, 비워 두면 코드가 그린 기본 그림을 쓴다. Higgsfield 등으로 만든 이미지는 여기에 끼운다. 방법은 README 참조.
